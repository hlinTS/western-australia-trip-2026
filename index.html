实用贴士

旅行中真正会用到的

🚗 10/8 提前还车

优先营业时间内当面交车；若晚于 17:30，按 No Birds after-hours 流程停车、锁车、投钥匙。拍摄车身四周、油表/里程、停车位置、锁车状态及 key-drop 过程。原订单还车时间仍为 10/9 11:00，留有次日营业时间缓冲。

⛽ 北线加油

长途段不要等油量很低才找油站。Geraldton 是重要补给点；Monkey Mia / Shark Bay、Kalbarri 一带价格和营业时间都可能更不友好。

🌇 尽量避免夜间北线驾驶

西澳乡间道路日落后野生动物风险明显上升。10/8 不要为了赶 17:30 还车而压缩安全余量，晚到就使用 after-hours return。

🐋 观鲸当天

10/10 09:00 开船，但把 08:30 当作真正的抵达时间。船程约2小时；海况变化大，出发前一天再看运营方通知。若容易晕船，早餐清淡并提前做好防晕准备。

🏝️ Rottnest

10:00 去、17:30 回；E-bike 为主方案，Island Explorer 保留为天气不佳时的备选。10/1 与10/6检查风雨；船票开船前5分钟停止登船。

🧳 10/10 行李

Warders 退房后先寄存 → 观鲸后回酒店取行李 → 火车到 Perth → Citiplace locker → Citywalk → 约20:30取行李 → 去机场。City of Perth 官方资料显示周六 Rest Centre 07:00–次日02:30，但 locker 仅可使用至22:00，所以不要把取行李拖到最后。

🌇 10/10 Perth Citywalk

建议路线：Perth Station 寄存 → London Court / St Georges Terrace → Elizabeth Quay → 公交去 Kings Park → 日落前后看城市与天鹅河 → 回CBD晚饭 → 约20:30取行李。这样不需要拖着箱子，也不会为了 Kings Park 徒步爬坡消耗太多体力。

🎟️ FamilyRider

按你现在住 Fremantle 的版本，10/9 基本步行去 B Shed，不值得买；10/10 两人从 Fremantle → Perth，再 Perth → Airport，FamilyRider 更有价值。购买时以当天 Transperth 售票规则为准。
